# 例图风格对齐

用户给一张例图 + 一张要修的照片，目标是**味道靠近**，不是像素匹配、不是套 LUT。

## 做什么

1. 导出当前照片 JPEG，对例图和当前图各做一次直方图指纹：亮度均值/中位、R−G / B−G、EV 跨度、高低区占比。
2. `settings_from_gap` 把差距映射到基本面板 + 一条点曲线（ fresher → 降对比/去雾，更亮 → 加曝光，更冷 → 降色温）。
3. LLM **先看两张图**，改幅度、补 HSL（水绿转青这类指纹代不到的）。
4. `apply_retouch`。

入口：`propose_style_match` / MCP `propose_style_match_photo`。不自动写入。

## 不做什么

- 不爬网下「大师作品」当训练集。版权、风格混杂、和钧的片子对不上。要学审美，用**钧指定的例图**。
- 不上扩散模型/自动上色。输出必须是 Lightroom develop，目录里可再改。
