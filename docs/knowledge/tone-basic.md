# 影调：基本面板在干什么

影调 = 画面里黑、灰、白怎么分布，不是「亮一点/暗一点」一句话。

## 三层，由粗到细

1. **曝光** — 整体平移。过曝高光难救，欠曝暗部还能捞。先保证高光不飞。
2. **基本面板分区** — 高光 / 阴影 / 白色 / 黑色。它们作用的亮度带不同，不是对比度的别名。
3. **曲线** — 对「输入亮度 → 输出亮度」的精确映射。基本面板搞不定的中间调、肩部、趾部，用曲线。

基本面板和曲线是**叠在一起**的，不是互斥。先用滑块把大关系摆正，再用曲线修层次。

## 滑块各自咬哪一段（8bit 直觉）

| 滑块 | 主要咬谁 | 典型用法 |
|---|---|---|
| 曝光 | 全体，中间调最明显 | 整体偏暗/偏亮时小幅 ±0.1~0.4 |
| 对比度 | 以中灰为界两边拉开，黑白场几乎不动 | 便宜的硬调；细活用曲线 |
| 高光 | 亮部，负向时压白场 | 天空、太阳、窗；负向比正向狠 |
| 阴影 | 暗部，正向时开细节 | 逆光主体；不要把夜景/剪影洗成白天 |
| 白色 | 最亮那一端（白点） | 通透；过大容易死白 |
| 黑色 | 最暗那一端（黑点） | 沉下去；过负死黑 |

经验：要拉开动态范围，往往是 **白色略加、黑色略减**；要保细节，是 **高光减、阴影加**。两者目的相反，别同时拉满。

## 色温 / 色调

- 色温：黄蓝轴。日落的金、港湾的青，经常是场景色，不是故障。
- 色调：绿品红轴。机内自动白平衡常偏品红，水面发脏时先减色调，再谈饱和。

直方图的「偏冷/偏品红」是证据，不是处方。先看图。

## 和 Lightroom「自动」的区别

Develop 的 Auto（2017 起 Sensei）只改 8 个滑块：曝光/对比/高光/阴影/白/黑/自然饱和/饱和。对照「职业修过的平均好看」训的，目标是中性起点。不碰白平衡、HSL、曲线、裁切。

插件动作 `set_auto_tone`（`LrDevelopController.setAutoTone`）就是按这个按钮。改 Lua 后要在插件管理器里 Reload。例图对齐和口令修不是 Auto。
