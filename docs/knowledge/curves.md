# 曲线

Lightroom 里有两套互不覆盖的曲线：

- **参数曲线** `ParametricShadows / Darks / Lights / Highlights`（约 -100~100）：按区段，过渡柔。
- **点曲线** `ToneCurvePV2012`（以及 R/G/B 通道）：输入→输出的折线。更狠，也更容易拧坏。

插件要求点曲线是 **0–255 整数对**，扁平数组，**必须以输入 0 开头、输入 255 结尾**，输入严格递增。

```
[0, 0,  64, 50,  128, 128,  192, 205,  255, 255]
 #x  y   x   y    x     y     x    y     x    y
```

同时把 `ToneCurveName2012` 设成 `"Custom"`。

## 常用形状（RGB 复合）

| 目的 | 点列 | 备注 |
|---|---|---|
| 直线（复位） | `[0,0, 255,255]` | Linear |
| 轻 S（加对比、保黑白场） | `[0,0, 64,56, 128,128, 192,200, 255,255]` | 肩/趾只动一点 |
| 中 S | `[0,0, 64,48, 128,128, 192,208, 255,255]` | 风光常用；高光易硬 |
| 提中间调、护高光 | `[0,0, 64,70, 128,140, 192,200, 255,255]` | 逆光主体 |
| 压中间调 | `[0,0, 128,110, 255,255]` | 雾天别把天洗白 |

通道曲线（少用）：红通道上提 = 加红，下压 = 偏青。S 形红曲线 = 高光偏暖、阴影偏青。港湾/夜景别拿通道曲线当白平衡。

## 和基本面板怎么分工

- 太阳/窗户死白：先高光/白色，再用点曲线把 192 附近略压。
- 雾里的楼要分开、但不要 HDR：去雾小幅 + 曲线轻 S，比对比度滑块干净。
- 剪影：不要用曲线去抬 0–32；那是把剪影拆掉。

一次曲线不超过 5 个点。拧坏了先回到直线，不要在坏曲线上继续加点。
