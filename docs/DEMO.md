# Demo 录制指南

Lightroom Agent（分析层）+ automaat/lightroom-mcp（传输层）的演示脚本。
每条演示约 1–2 分钟，按推荐顺序录制。

## 录制前准备（必做）

1. Lightroom Classic 打开，Plug-in Manager 里 Lightroom MCP 已 **Start Server**
2. **先做一次"暖连接"调用**（如读一次选中照片）——automaat 版插件空闲约 91 秒会
   重启连接，首次调用可能超时；暖连接后正式录制才不会卡壳
3. 图库中选中目标照片（演示 1/3 用单张，演示 2 用一组同批照片）
4. 确保 `lightroom-analysis` server 已加载（工具 `analyze_photo` 可见）

## Demo 1：单张诊断闭环（核心价值）

**叙事**：单用传输层能操作 Lightroom，但不知道照片状况 → 加上分析层，AI 能"看"了。

1. 读选中照片（`get_selected_photos`）→ 展示照片信息
2. 导出 1080px JPEG（`export_photos`）
3. 分析（`analyze_photo`）→ **高亮输出**：
   - 亮度均值/中位数、高光溢出 %、阴影死黑 %
   - 11 区分布、5×5 分区测光矩阵
   - 色偏判断 + 诊断建议
4. 结合照片参数甄别建议（如青橙风格下"偏冷"是误报）——展示判断力
5. 调参 → 撤销恢复

**讲解要点**："这一切都是数值、可复核；纯文本模型不猜画面内容。"

## Demo 2：批量一致性扫描（独有能力）

**叙事**：一百多张素材要收尾，先机器扫一遍找出需要单独处理的。

1. 把一批照片导出到目录（或直接用已有渲染图目录）
2. `batch_analyze(directory)` → 逐张表格（亮度/溢出/色偏/建议）
3. 指出 2–3 张影调离群的（如曝光差 >2EV 或溢出明显的）
4. 对离群者单独跑 Demo 1 的完整诊断

**讲解要点**："这个扫描在纯传输层做不到——它只负责导出/改参，不会告诉你哪张有问题。"

## Demo 3：调参效果验证

**叙事**：调整不是拍脑袋——改完用数据证明对不对。

1. `analyze_photo` 调前基线（记录高光溢出率等）
2. 传输层调参（如压高光 -30、提阴影 +40）
3. 重新导出 → 再次 `analyze_photo`
4. 对比前后指标（高光溢出 5%→1% 之类）→ 用数字说话

**讲解要点**："看→判断→调→验证 的闭环闭环，最后一步是别人没有的。"

## 录制工具建议

- macOS 自带 `Cmd+Shift+5` 录屏即可
- 输出对话 + 工具 JSON 结果画面为主；Lightroom 画面只在调参演示时切过去
- 字幕：每支 demo 开头一句话说清"这在解决什么问题"

## 常见翻车点

| 现象 | 对策 |
|---|---|
| 第一次调用超时 | 暖连接（先调一次轻量工具） |
| 导出报"缺少目标文件夹" | 先 `mkdir -p` 目标目录再导出 |
| 分析结果为空 | 确认导出的 JPEG 路径存在 |
| 选中照片变化 | 每支 demo 录制前重新确认选中 |
